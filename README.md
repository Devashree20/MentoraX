# MentoraX – A Digital Mentoring Platform

MentoraX is a web-based digital mentoring platform designed to simplify and manage the mentor–mentee process in educational institutions. It replaces traditional manual mentoring records with a centralized digital system.

### Features

* Role-based login for **Students, Mentors, and HOD**
* Student and mentor profile management
* Mentor–mentee management
* Student progress tracking
* Separate dashboards for each role
* Centralized mentoring records

### Tech Stack

* **Frontend:** React.js
* **Backend:** Django & Django REST Framework
* **Database:** PostgreSQL

### Project Purpose

MentoraX helps educational institutions efficiently manage mentoring activities, improve accessibility of student records, and provide a structured platform for communication and progress monitoring.
